# 🌟 Multiview reconstruction in Fiji using BigStitcher

This tutorial shows how to register and fuse multiview lightsheet datasets using [BigStitcher](https://imagej.net/plugins/bigstitcher) in [Fiji](https://fiji.sc).

## Getting started

The tutorial is available online at [bruvellu.github.io/multiview-tutorial](https://bruvellu.github.io/multiview-tutorial/).

### Offline usage

- Download the latest archive from GitHub ([here](https://github.com/bruvellu/multiview-tutorial/archive/refs/heads/main.zip)) or Zenodo ([here](https://doi.org/10.5281/zenodo.XXXXXXXXX))
- Unzip the archive in your working directory
- Open the file `multiview-tutorial.html` on your browser
